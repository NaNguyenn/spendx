# Aggregates never include expenses the viewer can't see

Every number a viewer sees — leaderboard totals, category breakdowns, any future social aggregate — is a sum over only the expenses that viewer could see itemized. Private expenses therefore leave no trace in anything shown to others, including the owner's own leaderboard row (which shows Shareable Spend, so standings are identical for all viewers); full spending appears only in the owner's personal statistics.

The rejected alternative — full totals with hidden items — leaks the existence and size of private spending (and, with category breakdowns, its kind). A visibility setting that leaks aggregates isn't a visibility setting.
